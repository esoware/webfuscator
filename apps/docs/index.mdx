`webfuscator` turns a JavaScript source string into harder-to-read JavaScript. It runs synchronously, performs no file I/O, and returns source code.

## Use it in a build script

Pass JavaScript to `obfuscate`, then write the returned string wherever your build expects it.

```js obfuscate.mjs highlight={5} lines
import { obfuscate } from 'webfuscator'

const source = `function square(value) { return value * value }`

const output = obfuscate(source, {
  minify: true,
  seed: 42,
  transforms: { renameIdentifiers: true },
})
```

## Know what the pipeline does

<Columns cols={3}>
  <Card title="Parses JavaScript" icon="code">
    Babel accepts scripts and ECMAScript modules with unambiguous source detection. Compile TypeScript, JSX, and other syntax extensions first.
  </Card>

  <Card title="Rewrites what it can prove safe" icon="route">
    Most passes preserve behavior and skip what they cannot prove safe. A few remove an effect or rename across a boundary you set, and those pages say so.
  </Card>

  <Card title="Prints source" icon="file-output">
    The API returns JavaScript only. It does not return an AST or generate a source map.
  </Card>
</Columns>

The same source, options, package version, and Node.js version produce the same output. Change `seed` when you want a different built-in randomized sequence.

<Info>
  Obfuscation does not hide client-side secrets or create a security boundary. Use `webfuscator` only on software you own or are authorized to modify. Read the project's [responsible-use policy](https://github.com/esoware/webfuscator/blob/main/DISCLOSURE).
</Info>
