## What it changes

Rewrites `true`, `false`, `NaN`, `undefined`, and `Infinity` as equivalent
expressions built from strings.

## Before and after

<CodeGroup>

```js title="Before" lines
if (x === undefined) return NaN;
var lim = !done ? Infinity : 0;
var flag = !x ? true : false;
```

```js title="After" lines
if (x === void "ab") return +"cd";
var lim = !done ? 1 / !"ef" : 0;
var flag = !x ? !!"gh" : !"ij";
```

</CodeGroup>

## Configuration

Run this transform by setting `transforms.specialsToStrings` to `true` or an options object:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    specialsToStrings: true,
  },
})
```

Pass `{ stringGeneratorMode }` instead of `true` to override its generated string style.
