## What it changes

Rewrites eligible async and generator object methods as function-valued
properties.

## Before and after

<CodeGroup>

```js title="Before" lines
const o = {
  async *stream() {},
  plain() {},
  get x() {
    return 1;
  },
};
```

```js title="After" lines
const o = {
  stream: async function* () {},
  plain() {},
  get x() {
    return 1;
  },
};
```

</CodeGroup>

## Configuration

Run this transform by setting `transforms.objectMethodToProperty` to `true`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    objectMethodToProperty: true,
  },
})
```
