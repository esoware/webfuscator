## Configuration

Use `transforms.logicalToTernary` in the options passed to `obfuscate`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    logicalToTernary: true,
  },
})
```

## What it changes

Rewrites logical expressions as guarded assignments or ternaries. A side-effectful left side is cached so it is evaluated once.

## Before and after

<CodeGroup>

```js title="Before" lines
var x = a || b;
y = c && d;
f(get() ?? fallback);
```

```js title="After" lines
var x = a;
if (!x) x = b;
y = c;
if (y) y = d;
f((_t = get()) != null ? _t : fallback);
```

</CodeGroup>
