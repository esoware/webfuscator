## What it changes

Rewrites logical expressions as equivalent conditional expressions or
guarded assignments while preserving short-circuit evaluation.

## Before and after

<CodeGroup>

```js title="Before" lines
var x = a || b;
y = c && d;
f(get() ?? fallback);
```

```js title="After" lines
var x = a;
if (!x) x = b;
y = c;
if (y) y = d;
f(((_t = get()) !== null ? _t !== void 0 : false) ? _t : fallback);
```

</CodeGroup>

## Configuration

Run this transform by setting `transforms.logicalToTernary` to `true`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    logicalToTernary: true,
  },
})
```
