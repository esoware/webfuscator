## What it changes

Moves eligible leading `var` declarations with literal initializers into
trailing default parameters.

## Before and after

<CodeGroup>

```js title="Before" lines
function run() {
  var x = 1;
  return x;
}
```

```js title="After" lines
function run(x = 1) {
  return x;
}
```

</CodeGroup>

## Configuration

Run this transform by setting `transforms.packDeclarationsIntoParameters` to `true`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    packDeclarationsIntoParameters: true,
  },
})
```
