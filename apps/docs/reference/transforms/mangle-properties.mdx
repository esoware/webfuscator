## What it changes

Renames statically known public properties using one consistent program-wide
mapping.

<Warning>
  Another file, a JSON payload, a template, the DOM, or reflection can still use a renamed property. The transform cannot see those uses. Restrict mangling to names whose reads and writes you control, using `regex`, `reserved`, annotations, or a reviewed `cache`.
</Warning>

## Before and after

<CodeGroup>

```js title="Before" lines
var counter = {
  current_: 1,
  increment_() { return ++this.current_; }
};
log(counter.increment_());
```

```js title="After" lines
var counter = {
  a: 1,
  b() { return ++this.a; }
};
log(counter.b());
```

</CodeGroup>

## Configuration

Run this transform by setting `transforms.mangleProperties` to `true` or an options object:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    mangleProperties: true,
  },
})
```

Pass [property-mangling options](/reference/property-mangling-options) instead of `true` when you need to limit which properties it changes.
