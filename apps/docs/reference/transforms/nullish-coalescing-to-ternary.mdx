## What it changes

Rewrites nullish-coalescing expressions as equivalent conditional expressions
while evaluating the left operand once.

## Before and after

<CodeGroup>

```js title="Before" lines
var x = a ?? b;
f(get() ?? fallback);
```

```js title="After" lines
var x = a;
if (x === null ? true : x === void 0) x = b;
f(((_t = get()) !== null ? _t !== void 0 : false) ? _t : fallback);
```

</CodeGroup>

## Configuration

Run this transform by setting `transforms.nullishCoalescingToTernary` to `true`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    nullishCoalescingToTernary: true,
  },
})
```
