## What it changes

Removes unused declarations and side-effect-free expression statements until
no further code becomes unused.

## Before and after

<CodeGroup>

```js title="Before" lines
function foo() { return "foo"; }
function bar() { return "bar"; }
var unused = 1;
foo();
```

```js title="After" lines
function foo() { return "foo"; }
foo();
```

</CodeGroup>

## Configuration

Run this transform by setting `transforms.removeUnusedCode` to `true`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    removeUnusedCode: true,
  },
})
```
