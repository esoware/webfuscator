## Configuration

Use `transforms.optionalChainingToTernary` in the options passed to `obfuscate`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    optionalChainingToTernary: true,
  },
})
```

## What it changes

Rewrites optional chains as nested ternaries. Side-effectful receivers are
cached, and member calls retain their `this`. Optional deletion short-circuits
to `true` as required by ECMA-262 13.5.1.

## Before and after

<CodeGroup>

```js title="Before" lines
obj?.m(arg);
delete obj?.x;
a?.b?.c;
```

```js title="After" lines
obj == null ? void 0 : (_m = obj.m).call(obj, arg);
obj == null ? true : delete obj.x;
a == null ? void 0 : (_b = a.b) == null ? void 0 : _b.c;
```

</CodeGroup>
