## Configuration

Use `transforms.collapseSingleUseTemps` in the options passed to `obfuscate`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    collapseSingleUseTemps: true,
  },
})
```

## What it changes

Drops single-use temporaries through substitution, direct branch writes, or
constant replacement. Sweeps continue until no shape exposes another.

## Before and after

<CodeGroup>

```js title="Before" lines
var _t;
if (cond) { _t = 1; } else { _t = 2; }
return _t;
```

```js title="After" lines
if (cond) { return 1; } else { return 2; }
```

</CodeGroup>
