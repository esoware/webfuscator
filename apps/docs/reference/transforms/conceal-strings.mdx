## What it changes

Replaces runtime string literals with calls to a generated decoder backed by
an obfuscated string vault.

<Warning>
  String concealment is obfuscation, not encryption. The generated decoder and vault contain everything needed to recover the original strings.
</Warning>

## Before and after

<CodeGroup>

```js title="Before" lines
function greet(name) {
  return "Hello, " + name;
}
```

```js title="After" lines
const _stringPool = " lo,He",
  _stringPayload = [0, 4, 7, 2, 2, 6, 2],
  _stringMetadata = [0, 7, 4, 5],
  _stringCache = [null],
  _stringDecoder = function (_entry) {
    let _cached = _stringCache[_entry];
    if (_cached !== null) return _cached;
    let _result = "",
      _record = _entry * 4,
      _start = _stringMetadata[_record],
      _length = _stringMetadata[_record + 1],
      _stringKey = _stringMetadata[_record + 2],
      _stringStep = _stringMetadata[_record + 3];
    for (let _position = 0; _position < _length; _position++) {
      let _stringMask = _stringKey + _position * _stringStep & 7;
      _result += _stringPool[_stringPayload[_start + _position] ^ _stringMask];
    }
    _stringCache[_entry] = _result;
    return _result;
  };
function greet(name) {
  return _stringDecoder(0) + name;
}
```

## Configuration

Run this transform by setting `transforms.concealStrings` to `true` or an options object:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    concealStrings: true,
  },
})
```

Pass `{ cache, cover, deduplicate, scope }` instead of `true`. Program scope is the default and uses one vault. Function scope creates separate function vaults, each with the same whole-program pool. The default `regional` cover fills U+0000-00FF plus every 256-unit page touched anywhere in the program. Use `used` for compact output or `full` for all 65,536 UTF-16 units. Disable `cache` to decode on every evaluation, or disable `deduplicate` to give equal literals separate entries.
