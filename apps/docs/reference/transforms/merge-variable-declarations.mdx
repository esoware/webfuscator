## What it changes

Merges adjacent compatible variable declarations into a single declaration.

## Before and after

<CodeGroup>

```js title="Before" lines
let a = 1;
let b = 2;
```

```js title="After" lines
let a = 1,
  b = 2;
```

</CodeGroup>

## Configuration

Run this transform by setting `transforms.mergeVariableDeclarations` to `true`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    mergeVariableDeclarations: true,
  },
})
```
