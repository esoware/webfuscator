## What it changes

Rewrites eligible conditional expressions as `if` statements, using a
temporary when their value is needed.

## Before and after

<CodeGroup>

```js title="Before" lines
var y = a ? b : c;
log(d ? e : f);
```

```js title="After" lines
var y;
if (a) { y = b; } else { y = c; }
var _ternaryResult;
if (d) { _ternaryResult = e; } else { _ternaryResult = f; }
log(_ternaryResult);
```

</CodeGroup>

## Configuration

Run this transform by setting `transforms.ternaryToIf` to `true`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    ternaryToIf: true,
  },
})
```
