## What it changes

Combines adjacent expression statements with the comma operator and moves
them into a following compatible statement when execution order is preserved.

## Before and after

<CodeGroup>

```js title="Before" lines
function run() {
  prepare();
  update();
  return finish();
}
```

```js title="After" lines
function run() {
  return prepare(), update(), finish();
}
```

</CodeGroup>

## Configuration

Run this transform by setting `transforms.packExpressions` to `true`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    packExpressions: true,
  },
})
```
