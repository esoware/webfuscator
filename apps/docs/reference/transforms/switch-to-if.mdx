## What it changes

Rewrites eligible `switch` statements as equivalent `if` statements, using a
labeled block when fallthrough must be preserved. Switches whose shared case
scope cannot be preserved stay unchanged.

## Before and after

<CodeGroup>

```js title="Before" lines
switch (x) {
  case 1: a(); break;
  case 2: b();
  case 3: c(); break;
  default: d();
}
```

```js title="After" lines
_switch: {
  var _switchValue = x;
  var _switchFall = false;
  if (_switchFall || _switchValue === 1) { _switchFall = true; a(); break _switch; }
  if (_switchFall || _switchValue === 2) { _switchFall = true; b(); }
  if (_switchFall || _switchValue === 3) { _switchFall = true; c(); break _switch; }
  d();
}
```

</CodeGroup>

## Configuration

Run this transform by setting `transforms.switchToIf` to `true`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    switchToIf: true,
  },
})
```
