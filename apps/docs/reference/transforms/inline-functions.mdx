## What it changes

Replaces eligible function calls with the called function's body and removes
declarations that become unused.

## Before and after

<CodeGroup>

```js title="Before" lines
function id(x) { return x; }
var y = id(compute());
```

```js title="After" lines
var _x = compute();
var y = _x;
```

</CodeGroup>

## Configuration

Run this transform by setting `transforms.inlineFunctions` to `true`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    inlineFunctions: true,
  },
})
```
