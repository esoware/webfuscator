## What it changes

Moves hoisted function declarations to the end of their statement lists
without changing their relative order.

## Before and after

<CodeGroup>

```js title="Before" lines
function area(r) {
  return r * r;
}
log(area(2));
```

```js title="After" lines
log(area(2));
function area(r) {
  return r * r;
}
```

</CodeGroup>

## Configuration

Run this transform by setting `transforms.reorderFunctionDeclarations` to `true`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    reorderFunctionDeclarations: true,
  },
})
```
