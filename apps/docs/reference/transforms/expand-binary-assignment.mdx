## What it changes

Expands arithmetic and bitwise compound assignments into simple assignments
while preserving single evaluation of member receivers and computed keys.

## Before and after

<CodeGroup>

```js title="Before" lines
a += b;
a **= 2;
obj.x -= y;
arr[idx()] |= v;
```

```js title="After" lines
a = a + b;
a = a ** 2;
(_obj = obj).x = _obj.x - y;
(_arr = arr)[_idx = idx()] = _arr[_idx] | v;
```

</CodeGroup>

## Configuration

Run this transform by setting `transforms.expandBinaryAssignment` to `true`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    expandBinaryAssignment: true,
  },
})
```
