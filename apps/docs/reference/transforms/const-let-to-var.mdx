## What it changes

Converts eligible `let` and `const` declarations to `var`, renaming bindings
when needed to avoid hoisting conflicts. Loop bindings stay unchanged when
conversion would alter iteration behavior.

## Before and after

<CodeGroup>

```js title="Before" lines
function f() {
  const x = 1;
  return x;
}
```

```js title="After" lines
function f() {
  var x = 1;
  return x;
}
```

</CodeGroup>

## Configuration

Run this transform by setting `transforms.constLetToVar` to `true`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    constLetToVar: true,
  },
})
```
