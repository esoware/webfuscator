## Configuration

Use `transforms.constLetToVar` in the options passed to `obfuscate`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    constLetToVar: true,
  },
})
```

## What it changes

Converts safe `let` and `const` declarations to `var` and renames bindings
that would conflict after hoisting. It skips TDZ reads, reassigned constants,
captured loop bindings, uninitialized loop heads, script globals, and `with`.

## Before and after

<CodeGroup>

```js title="Before" lines
function f() {
  const x = 1;
  return x;
}
```

```js title="After" lines
function f() {
  var x = 1;
  return x;
}
```
