## What it changes

Expands logical compound assignments into equivalent short-circuiting
assignments while preserving single evaluation of member receivers and
computed keys.

## Before and after

<CodeGroup>

```js title="Before" lines
a ||= b;
a &&= b;
a ??= b;
obj.x ||= y;
arr[idx()] ??= v;
```

```js title="After" lines
a || (a = b);
a && (a = b);
a ?? (a = b);
(_obj = obj).x || (_obj.x = y);
(_arr = arr)[_idx = idx()] ?? (_arr[_idx] = v);
```

</CodeGroup>

## Configuration

Run this transform by setting `transforms.expandLogicalAssignment` to `true`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    expandLogicalAssignment: true,
  },
})
```
