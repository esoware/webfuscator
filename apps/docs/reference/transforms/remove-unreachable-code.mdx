## What it changes

Removes unreachable statements that follow unconditional control flow while
retaining declarations whose hoisting can still be observed.

## Before and after

<CodeGroup>

```js title="Before" lines
function foo() {
  return "bar";
  log("baz");
}
```

```js title="After" lines
function foo() {
  return "bar";
}
```

</CodeGroup>

## Configuration

Run this transform by setting `transforms.removeUnreachableCode` to `true`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    removeUnreachableCode: true,
  },
})
```
