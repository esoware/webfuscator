## Configuration

Use `transforms.constToLet` in the options passed to `obfuscate`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    constToLet: true,
  },
})
```

## What it changes

Changes `const` to `let` when no write can observe the lost TypeError. Direct
eval and recorded constant violations keep the declaration unchanged. Scope
and TDZ behavior are otherwise identical.

## Before and after

<CodeGroup>

```js title="Before" lines
const foo = "bar";
const { a, b } = obj;
```

```js title="After" lines
let foo = "bar";
let { a, b } = obj;
```

</CodeGroup>
