## What it changes

Rewrites eligible numeric update expressions as compound assignments. Postfix
updates stay unchanged when their original value is used.

## Before and after

<CodeGroup>

```js title="Before" lines
let i = 0;
i++;
arr[++i] = 1;
let n = 5n;
n++;
```

```js title="After" lines
let i = 0;
i += 1;
arr[i += 1] = 1;
let n = 5n;
n++;
```

</CodeGroup>

## Configuration

Run this transform by setting `transforms.updateToAssignment` to `true`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    updateToAssignment: true,
  },
})
```
