## What it changes

Replaces eligible numeric `arguments[i]` reads with the corresponding
parameter in sloppy functions with simple parameter lists.

## Before and after

<CodeGroup>

```js title="Before" lines
function foo(bar) {
  log(arguments[0]);
}
```

```js title="After" lines
function foo(bar) {
  log(bar);
}
```

</CodeGroup>

## Configuration

Run this transform by setting `transforms.argumentsToParameters` to `true`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    argumentsToParameters: true,
  },
})
```
