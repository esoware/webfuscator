## Configuration

Use `transforms.yodifyConditions` in the options passed to `obfuscate`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    yodifyConditions: true,
  },
})
```

## What it changes

Moves a right operand made from literals and unary operators to the left of a
comparison when swapping does not change coercion order. Relational operators
are flipped after swapping.

## Before and after

<CodeGroup>

```js title="Before" lines
if (x === 1) {}
if (name !== "foo") {}
if (count > 5) {}
if (idx <= 10) {}
```

```js title="After" lines

if ("foo" !== name) {}
if (5 < count) {}
if (10 >= idx) {}
```
