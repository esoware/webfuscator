## What it changes

Serializes the program and executes it through a generated `Function`
constructor.

<Warning>
  `pack` runs the generated string as a `Function` body. `import.meta` and top-level `await` are syntax errors there. A top-level `arguments` refers to the generated function. `pack` rejects export statements before producing output.
</Warning>

## Before and after

<CodeGroup>

```js title="Before" lines
console.log(value);
```

```js title="After" lines
Function("M", "console.log(M[\"b\"]);")({
  get "b"() {
    return value;
  }
});
```

</CodeGroup>

## Configuration

Run this transform by setting `transforms.pack` to `true` or an options object:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    pack: true,
  },
})
```

Pass `{ escapeStrict, skipGlobals, stringGeneratorMode }` instead of `true`. `escapeStrict` removes strict mode from the generated function. `skipGlobals` defaults to `true`, which leaves standard globals as direct references. Set it to `false` to route every free name through accessors. An array replaces the default list. Every listed name must be visible inside a generated `Function`.
