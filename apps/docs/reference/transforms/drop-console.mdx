## What it changes

Removes eligible `console` call expression statements.

<Note>
  This option removes console output. It removes a call only when evaluating its arguments and computed key has no other side effects. Calls through a shadowed or reassigned `console` stay unchanged.
</Note>

## Before and after

<CodeGroup>

```js title="Before" lines
function foo() {
  console.log("hi");
  return "bar";
}
function bar(console) {
  console.log("kept");
}
```

```js title="After" lines
function foo() {
  return "bar";
}
function bar(console) {
  console.log("kept");
}
```

</CodeGroup>

## Configuration

Run this transform by setting `transforms.dropConsole` to `true`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    dropConsole: true,
  },
})
```
