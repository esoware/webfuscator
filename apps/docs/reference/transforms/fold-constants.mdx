## What it changes

Replaces pure compile-time constant expressions with equivalent literals or
selected branches.

## Before and after

<CodeGroup>

```js title="Before" lines
var v = 1 + 2 * 3;
if (true && cond) f();
```

```js title="After" lines
var v = 7;
if (cond) f();
```

</CodeGroup>

## Configuration

Run this transform by setting `transforms.foldConstants` to `true`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    foldConstants: true,
  },
})
```
