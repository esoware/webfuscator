## What it changes

Rewrites eligible function declarations in scripts and function bodies as
`var`-initialized function expressions. Declarations stay unchanged when
moving initialization to their statement position could alter execution.

## Before and after

<CodeGroup>

```js title="Before" lines
const TAX = 0.2;
function withTax(n) {
  return n + n * TAX;
}
total = withTax(100);
```

```js title="After" lines
const TAX = 0.2;
var withTax = function (n) {
  return n + n * TAX;
};
total = withTax(100);
```

</CodeGroup>

## Configuration

Run this transform by setting `transforms.functionDeclarationToExpression` to `true`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    functionDeclarationToExpression: true,
  },
})
```
