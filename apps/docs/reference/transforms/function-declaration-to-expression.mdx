## Configuration

Use `transforms.functionDeclarationToExpression` in the options passed to `obfuscate`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    functionDeclarationToExpression: true,
  },
})
```

## What it changes

Rewrites function declarations at script top level or directly inside a
function body as `var` initializers. It leaves a declaration unchanged when
an earlier statement could execute user code before the assignment.

Name inference and recursive references still use the `var` binding.

Block-level and module top-level declarations stay unchanged.

## Before and after

<CodeGroup>

```js title="Before" lines
const TAX = 0.2;
function withTax(n) {
  return n + n * TAX;
}
total = withTax(100);
```

```js title="After" lines
const TAX = 0.2;
var withTax = function (n) {
  return n + n * TAX;
};
total = withTax(100);
```

</CodeGroup>
