## What it changes

Rewrites classic `for` loops as equivalent `while` loops. `for...in` and
`for...of` loops stay unchanged.

## Before and after

<CodeGroup>

```js title="Before" lines
for (var i = 0; i < 3; i++) {
  if (skip(i)) {
    continue;
  }
  log(i);
}
```

```js title="After" lines
var i = 0;
while (i < 3) {
  _forIter: {
    if (skip(i)) {
      break _forIter;
    }
    log(i);
  }
  i++;
}
```

</CodeGroup>

## Configuration

Run this transform by setting `transforms.forToWhile` to `true`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    forToWhile: true,
  },
})
```
