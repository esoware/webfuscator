## Configuration

Use `transforms.hoistVariables` in the options passed to `obfuscate`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    hoistVariables: true,
  },
})
```

## What it changes

Moves `var` declarations to the start of their var scope without moving
initializer evaluation.

Direct exports and declarations inside `with` stay in place. Static blocks
keep separate declarations.

## Before and after

<CodeGroup>

```js title="Before" lines
function f() {
  var x = 1;
  if (c) {
    var y = g();
  }
  return x + y;
}
```

```js title="After" lines
function f() {
  var x, y;
  x = 1;
  if (c) {
    y = g();
  }
  return x + y;
}
```

</CodeGroup>
