## What it changes

Moves `var` declarations to the beginning of their containing function or
program without moving initializer evaluation.

## Before and after

<CodeGroup>

```js title="Before" lines
function f() {
  var x = 1;
  if (c) {
    var y = g();
  }
  return x + y;
}
```

```js title="After" lines
function f() {
  var y, x;
  x = 1;
  if (c) {
    y = g();
  }
  return x + y;
}
```

</CodeGroup>

## Configuration

Run this transform by setting `transforms.hoistVariables` to `true`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    hoistVariables: true,
  },
})
```
