## What it changes

Rewrites `do...while` loops as equivalent `while` loops while preserving
`continue` behavior.

## Before and after

<CodeGroup>

```js title="Before" lines
do {
  step();
  if (skip()) continue;
  log();
} while (more());
```

```js title="After" lines
while (true) {
  _doIteration: {
    step();
    if (skip()) break _doIteration;
    log();
  }
  if (!more()) break;
}
```

</CodeGroup>

## Configuration

Run this transform by setting `transforms.doWhileToWhile` to `true`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    doWhileToWhile: true,
  },
})
```
