## Configuration

Use `transforms.removeAnonymousFunctionNames` in the options passed to `obfuscate`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    removeAnonymousFunctionNames: true,
  },
})
```

## What it changes

Removes a function expression's name when the body does not use its binding
and NamedEvaluation restores the same `.name`. Other positions could infer no
name or a different one.

## Before and after

<CodeGroup>

```js title="Before" lines
var greet = function greet() {};
var a = function bar() {};
```

```js title="After" lines
var greet = function () {};
var a = function bar() {};
```
