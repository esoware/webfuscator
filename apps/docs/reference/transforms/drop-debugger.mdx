## What it changes

Removes every `debugger` statement.

<Note>
  Removing every `debugger` statement is the point, so this changes behavior.
</Note>

## Before and after

<CodeGroup>

```js title="Before" lines
function foo() {
  debugger;
  return "bar";
}
```

```js title="After" lines
function foo() {
  return "bar";
}
```

</CodeGroup>

## Configuration

Run this transform by setting `transforms.dropDebugger` to `true`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    dropDebugger: true,
  },
})
```
