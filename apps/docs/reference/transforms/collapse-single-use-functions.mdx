## What it changes

Moves eligible function declarations to their only references as anonymous
function expressions.

## Before and after

<CodeGroup>

```js title="Before" lines
function greet(name) {
  return 'hi ' + name;
}
button.addEventListener('click', greet);
```

```js title="After" lines
button.addEventListener('click', function (name) {
  return 'hi ' + name;
});
```

</CodeGroup>

## Configuration

Run this transform by setting `transforms.collapseSingleUseFunctions` to `true`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    collapseSingleUseFunctions: true,
  },
})
```
