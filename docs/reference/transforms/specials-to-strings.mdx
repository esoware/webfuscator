## Configuration

Use `transforms.specialsToStrings` in the options passed to `obfuscate`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    specialsToStrings: true,
  },
})
```

Pass `{ stringGeneratorMode }` instead of `true` to override its generated string style.

## What it changes

Rewrites five constant-like values through string expressions:

  - `true`     -> `!!"<random>"`
  - `false`    -> `!"<random>"`
  - `NaN`      -> `+"<random>"`
  - `undefined`-> `void "<random>"`
  - `Infinity` -> `1/!"<random>"`

Generated strings are nonempty and nonnumeric, fixing their truthiness and
numeric coercion.

`NaN`, `Infinity`, and `undefined` require genuine global reads. Delete and
write positions stay unchanged because the replacement is not a reference.
