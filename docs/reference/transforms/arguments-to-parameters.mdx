## Configuration

Use `transforms.argumentsToParameters` in the options passed to `obfuscate`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    argumentsToParameters: true,
  },
})
```

## What it changes

Replaces `arguments[i]` reads with their mapped parameter in sloppy functions
with simple parameter lists. Writes, deletion, reassigned parameters, and any
escape of the arguments object make the mapping unsafe. Missing parameters
are never added because that would change `fn.length`.

## Before and after

<CodeGroup>

```js title="Before" lines
function foo(bar) {
  log(arguments[0]);
}
```

```js title="After" lines
function foo(bar) {
  log(bar);
}
```

</CodeGroup>
