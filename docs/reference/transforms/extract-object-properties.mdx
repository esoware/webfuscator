## Configuration

Use `transforms.extractObjectProperties` in the options passed to `obfuscate`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    extractObjectProperties: true,
  },
})
```

## What it changes

Replaces a constant object or array wrapper with one binding per entry when
every reference is a static-key read. The inliner can then see function
values directly.

## Before and after

<CodeGroup>

```js title="Before" lines
var ops = {
  double: function (x) { return x * 2; },
  negate: function (x) { return -x; },
};
log(ops.double(3), ops.negate(7));
```

```js title="After" lines
var double = function (x) { return x * 2; };
var negate = function (x) { return -x; };
log(double(3), negate(7));
```

</CodeGroup>
