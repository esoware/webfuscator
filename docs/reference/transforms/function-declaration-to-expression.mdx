## Configuration

Use `transforms.functionDeclarationToExpression` in the options passed to `obfuscate`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    functionDeclarationToExpression: true,
  },
})
```

## What it changes

Rewrites safe function declarations as `var` initializers. The function value
is no longer hoisted, so nothing may observe the binding before assignment.

Preceding statements must be inert. Name inference and recursive references
still use the `var` binding.

Block-level declarations and module top-level declarations stay unchanged due
to Annex B aliases and live exports.

## Before and after

<CodeGroup>

```js title="Before" lines
const TAX = 0.2;
function withTax(n) {
  return n + n * TAX;
}
total = withTax(100);
```

```js title="After" lines
const TAX = 0.2;
var withTax = function (n) {
  return n + n * TAX;
};
total = withTax(100);
```

</CodeGroup>
