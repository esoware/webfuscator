## Configuration

Use `transforms.constLetToVar` in the options passed to `obfuscate`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    constLetToVar: true,
  },
})
```

## What it changes

Lifts safe lexical declarations to function-scoped `var`, renaming collisions
caused by hoisting. TDZ reads, reassigned constants, captured loop bindings,
uninitialized loop heads, program scope, `with`, and direct eval are refused.

## Before and after

<CodeGroup>

```js title="Before" lines
function f() {
  const x = 1;
  return x;
}
```

```js title="After" lines
function f() {
  var x = 1;
  return x;
}
```
