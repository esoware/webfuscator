## Configuration

Use `transforms.dropDebugger` in the options passed to `obfuscate`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    dropDebugger: true,
  },
})
```

## What it changes

Removes every `debugger` statement.

## Before and after

<CodeGroup>

```js title="Before" lines
function foo() {
  debugger;
  return "bar";
}
```

```js title="After" lines
function foo() {
  return "bar";
}
```
