## Configuration

Use `transforms.removeUnreachableCode` in the options passed to `obfuscate`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    removeUnreachableCode: true,
  },
})
```

## What it changes

Removes statements after unconditional control flow in the same statement list.

Hoisted function and `var` declarations stay because reachable code may still
observe their bindings.
