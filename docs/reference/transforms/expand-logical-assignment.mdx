## Configuration

Use `transforms.expandLogicalAssignment` in the options passed to `obfuscate`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    expandLogicalAssignment: true,
  },
})
```

## What it changes

Rewrites `||=`/`&&=`/`??=` as `LHS op (LHS = RHS)`. Member objects and
computed keys are cached so the read and write use the same receiver.

## Before and after

<CodeGroup>

```js title="Before" lines
a ||= b;
a &&= b;
a ??= b;
obj.x ||= y;
arr[idx()] ??= v;
```

```js title="After" lines
a || (a = b);
a && (a = b);
a ?? (a = b);
(_obj = obj).x || (_obj.x = y);
(_arr = arr)[_idx = idx()] ?? (_arr[_idx] = v);
```

</CodeGroup>
