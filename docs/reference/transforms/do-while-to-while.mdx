## Configuration

Use `transforms.doWhileToWhile` in the options passed to `obfuscate`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    doWhileToWhile: true,
  },
})
```

## What it changes

Rewrites `do` loops as `while (true)` with an exit test after the body.
Continues become breaks from an inner block so they still reach that test.
The inner label is omitted when nothing uses it.

## Before and after

<CodeGroup>

```js title="Before" lines
do {
  step();
  if (skip()) continue;
  log();
} while (more());
```

```js title="After" lines
while (true) {
  _doIteration: {
    step();
    if (skip()) break _doIteration;
    log();
  }
  if (!more()) break;
}
```

</CodeGroup>
