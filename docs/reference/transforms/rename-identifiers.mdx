## Configuration

Use `transforms.renameIdentifiers` in the options passed to `obfuscate`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    renameIdentifiers: true,
  },
})
```

Pass `{ stringGeneratorMode }` instead of `true` to override its generated string style.

## What it changes

Renames bindings and labels with the configured string generator. Each scope avoids
live ancestor names but otherwise restarts the cursor, allowing safe reuse in
sibling scopes.
