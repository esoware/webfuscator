## Configuration

Use `transforms.dropConsole` in the options passed to `obfuscate`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    dropConsole: true,
  },
})
```

## What it changes

Removes `console.*(...)` expression statements when `console` is not
locally shadowed. Matches dot, bracket, and optional-chain forms.
Leaves indirect uses alone (`console.log.call(...)`, assignments,
`await console.log(...)`).

## Before and after

<CodeGroup>

```js title="Before" lines
function foo() {
  console.log("hi");

}
```

```js title="After" lines
function foo() {
  return "bar";
}
function bar(console) {
  console.log("kept");
}
```
