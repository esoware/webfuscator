## Configuration

Use `transforms.mangleProperties` in the options passed to `obfuscate`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    mangleProperties: true,
  },
})
```

Pass [property-mangling options](/reference/property-mangling-options) instead of `true` when you need to limit which properties it changes.

## What it changes

Renames statically known public properties through one program-wide mapping.
Property selection follows Terser, with extra collision checks for names
that must remain unchanged.

## Before and after
