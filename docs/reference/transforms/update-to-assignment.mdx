## Configuration

Use `transforms.updateToAssignment` in the options passed to `obfuscate`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    updateToAssignment: true,
  },
})
```

## What it changes

Rewrites numeric updates as compound assignments. Prefix
results already match. Postfix forms require a position that discards the old
value.

BigInt differs because adding the number `1` throws. Only bindings proven to
stay numeric are rewritten. Members and parameters stay unchanged.

## Before and after

<CodeGroup>

```js title="Before" lines
let i = 0;
i++;
arr[++i] = 1;
let n = 5n;
n++;
```

```js title="After" lines
let i = 0;
i += 1;
arr[i += 1] = 1;
let n = 5n;
n++;
```
