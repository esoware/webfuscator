## Configuration

Use `transforms.nullishCoalescingToTernary` in the options passed to `obfuscate`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    nullishCoalescingToTernary: true,
  },
})
```

## What it changes

Rewrites `a ?? b` as a guarded assignment or `a != null ? a : b`. A
side-effectful left side is cached. Loose inequality checks both nullish
values in one comparison.

## Before and after

<CodeGroup>

```js title="Before" lines
var x = a ?? b;
f(get() ?? fallback);
```

```js title="After" lines
var x = a;
if (x == null) x = b;
f((_t = get()) != null ? _t : fallback);
```

</CodeGroup>
