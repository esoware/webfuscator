## Configuration

Use `transforms.inlineFunctions` in the options passed to `obfuscate`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    inlineFunctions: true,
  },
})
```

## What it changes

Replaces eligible calls with function bodies, working from inner calls out.
Declarations are removed after their last reference disappears.

## Before and after

<CodeGroup>

```js title="Before" lines
function id(x) { return x; }
var y = id(compute());
```

```js title="After" lines
var _x = compute();
var y = _x;
```

</CodeGroup>
