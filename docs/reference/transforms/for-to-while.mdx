## Configuration

Use `transforms.forToWhile` in the options passed to `obfuscate`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    forToWhile: true,
  },
})
```

## What it changes

Rewrites classic `for` loops as an initializer followed by `while`. Continues
become breaks from an inner block so the update still runs. Iterator loops
stay unchanged.

## Before and after

<CodeGroup>

```js title="Before" lines
for (var i = 0; i < 3; i++) {
  if (skip(i)) {
    continue;
  }
  log(i);
}
```

```js title="After" lines
var i = 0;
while (i < 3) {
  _forIter: {
    if (skip(i)) {
      break _forIter;
    }
    log(i);
  }
  i++;
}
```

</CodeGroup>
