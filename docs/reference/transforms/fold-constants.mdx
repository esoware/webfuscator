## Configuration

Use `transforms.foldConstants` in the options passed to `obfuscate`:

```js obfuscate.mjs highlight={3}
const output = obfuscate(source, {
  transforms: {
    foldConstants: true,
  },
})
```

## What it changes

Folds pure constant expressions to literals via `evaluateConstant`.
Logical and conditional nodes can fold directly to a chosen nonliteral branch.

## Before and after

<CodeGroup>

```js title="Before" lines
var v = 1 + 2 * 3;
if (true && cond) f();
```

```js title="After" lines
var v = 7;
if (cond) f();
```
