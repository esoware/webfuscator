Pass an `ObfuscatorOptions` object as the second argument to `obfuscate`. Every field is optional.

```ts ObfuscatorOptions
interface ObfuscatorOptions {
  minify?: boolean
  verbose?: boolean
  transforms?: TransformsMap
  stringGeneratorMode?: StringGeneratorMode | readonly StringGeneratorMode[]
  seed?: number
}
```

## `minify`

Type: `boolean`<br />Default: `false`

Passes Babel's `minified` flag to the generator, removing optional whitespace and line breaks from the returned JavaScript.

## `verbose`

Type: `boolean`<br />Default: `false`

Prints the name and elapsed milliseconds of each executed stage to standard error. It does not change the returned source.

## `transforms`

Type: object<br />Default: `{}`

All configurable transforms are disabled by default; set a key to `true` or an options object to enable it.

`renameIdentifiers` and `specialsToStrings` also accept `{ stringGeneratorMode }`. `pack` accepts `{ escapeStrict, stringGeneratorMode }`. `mangleProperties` accepts its [property options](/reference/property-mangling-options).

```js Enable selected transforms
const output = obfuscate(source, {
  transforms: {
    foldConstants: true,
    numbersToStrings: true,
  },
})
```

## `stringGeneratorMode`

Type: `'mangled' | 'hexadecimal' | 'randomized' | 'zeroWidth' | 'number' | readonly StringGeneratorMode[]`<br />Default: `'mangled'`

Sets the default style for generated identifiers, labels, property names, and string contents. An array mixes its modes with the seeded random source. An empty array is invalid.

See [String generator modes](/reference/string-generator-modes).

## `seed`

Type: `number`<br />Default: `0`

Seeds built-in randomized choices. The same seed and other inputs produce the same output for fixed package and Node.js versions. This random source is not cryptographic.
